# Kubernetes Advanced - Lab 1: Namespace

Selamat datang di lab pertama seri **Kubernetes Advanced**.

Di Kubernetes, Namespace dipakai untuk membagi satu cluster menjadi beberapa area kerja yang terpisah. Pemisahan ini berguna saat cluster dipakai oleh beberapa environment, aplikasi, atau tim.

Contoh penggunaan Namespace:

1. `dev` untuk pengembangan aplikasi.
2. `staging` untuk pengujian sebelum rilis.
3. `prod` untuk aplikasi production.
4. `team-a` dan `team-b` untuk memisahkan resource tiap tim.

Pada lab ini kamu akan berlatih membuat Namespace, memahami aturan nama resource, dan membuktikan bahwa nama Deployment yang sama dapat digunakan pada Namespace yang berbeda.

Klik **Start** untuk memulai.
