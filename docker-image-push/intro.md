# Lab — Build & Push Docker Image

Lab ini diringkas menjadi 4 langkah utama: membuat image, uji lokal, push ke Docker Hub, lalu pull dan run kembali.

## Tujuan

Setelah menyelesaikan lab ini, kamu akan mampu:

- Membuat Dockerfile sederhana
- Build dan uji Docker Image secara lokal
- Login, tag, dan push image ke Docker Hub
- Pull dan jalankan image dari Docker Hub

## Alur Singkat

```text
Dockerfile -> build -> test lokal -> login/tag/push -> pull/run
```

Klik Start dan ikuti Step 1 sampai Step 4.
