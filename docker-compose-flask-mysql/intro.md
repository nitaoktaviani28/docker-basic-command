# Docker Compose - Flask dan MySQL

Selamat datang di lab Docker Compose.

Pada lab ini, kamu akan membangun aplikasi Flask sederhana yang menyimpan nama ke database MySQL. Docker Compose akan menjalankan keduanya sebagai satu environment.

Konsep yang dipraktikkan:

1. Membuat aplikasi Python dan Dockerfile.
2. Menjalankan aplikasi dan MySQL dengan `docker compose`.
3. Menghubungkan service melalui DNS internal Compose.
4. Menggunakan bridge network dan named volume.
5. Membuktikan data tetap ada setelah container dibuat ulang.

Klik **Start** untuk memulai.
